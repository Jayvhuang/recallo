Interleaved practice generator交错练习生成器

A textbook exercise set tells you which method to use before you read the problem. Real tests do not. Paste your topics and this produces a practice order that keeps similar items apart, so choosing the method becomes part of the practice.课后习题在你读题之前就已经告诉你该用哪个方法。真实考试不会。把你的主题贴进来，本工具会生成一个"把同类题分开"的练习顺序，让"选方法"本身成为练习的一部分。

How this works它的原理

Blocked practice hides the hardest step按类练习掩盖了最难的一步

When twelve problems in a row need the same theorem, you never practise identifying which theorem applies. Interleaving restores that step — which is why it feels harder while you do it and pays off when the exam mixes everything.当连续十二道题都用同一个定理，你就从未练过"判断该用哪个定理"。交错把这一步还给你——所以做的时候更难受，而在考试把所有内容混在一起时才见效。

The measured benefit grows with delay实测优势随延迟增长

In a three-month classroom experiment with 126 seventh-graders, the same practice problems arranged in interleaved order beat blocked order with Cohen’s d = 0.42 on a test one day later and 0.79 thirty days later. The workload was identical; only the order changed.在一项为期三个月、126 名七年级学生的课堂实验中，同样的练习题按交错顺序排列，比按类排列在一天后的测试上高出 Cohen’s d = 0.42，在三十天后高出 0.79。工作量完全相同，改变的只有顺序。

Interleave discriminable things要交错"需要区分"的东西

The benefit comes from having to discriminate between approaches that could plausibly apply. Shuffling genuinely unrelated subjects mostly adds switching cost without that discrimination practice, so group by "things I confuse", not by timetable.收益来自"必须在几种都可能适用的方法之间做区分"。把彼此毫无关系的科目乱洗，多半只增加切换成本，而没有那份区分练习。所以按"我容易混的东西"分组，而不是按课表。

Questions常见问题

What is interleaved practice?什么是交错练习？

Rearranging a practice set so consecutive items require different methods, instead of doing all of one type before moving on. The total amount of practice is unchanged — only the order — and the change forces you to select the method rather than apply a pre-announced one.把练习集重排，使相邻的题目需要不同的方法，而不是做完一类再换下一类。练习总量不变——只有顺序变了——而这个改变逼你自己选方法，而不是套用已被告知的那一个。

Why does interleaving feel worse while it works better?为什么交错练着更难受、效果却更好？

Because performance during practice and learning are not the same thing. Interleaving lowers your accuracy in the session while raising retention later, so the felt signal points the wrong way. This is why people abandon it despite the measured delayed-test advantage.因为"练习时的表现"和"学到的东西"是两件事。交错会降低当场的正确率，却提高之后的留存，于是主观信号指向反方向。这就是为什么尽管延迟测试上有实测优势，人们还是会放弃它。

Should everything be interleaved?所有内容都该交错吗？

No. When a method is brand new, a short blocked run to get the mechanics right is sensible; interleaving pays once you have more than one candidate method and the risk is confusing them. First learn the move, then practise choosing it.不。当一个方法刚学，先按类连做一小段把机械步骤走顺是合理的；交错的收益出现在"你已经有不止一个候选方法、风险在于混淆它们"之后。先学会这一招，再练"什么时候用它"。
